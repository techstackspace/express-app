# Resources

Below are the [resources for this tutorial](https://arc.net/folder/E68FF896-B0A4-4188-AAA2-A51CCB06A4D1):

* **[Visual Studio Code](https://code.visualstudio.com/):** A free, powerful, and extensible code editor from Microsoft, ideal for development across Node.js, Git, debugging, and more.

* **[Chocolatey](https://chocolatey.org/):** The go‑to Windows package manager that automates installation via `choco`, wrapping installers, zips, scripts, and more.

* **[Git](https://git-scm.com/):** The essential distributed version control system, widely used for managing code history and collaboration.

* **[GitHub CLI (gh)](https://cli.github.com/):** Brings GitHub workflows—issues, PRs, releases—into your terminal, letting you script and manage your projects from the command line.

* **[Bun](https://bun.com/):** A new all‑in‑one JavaScript/TypeScript runtime with fast bundling, testing, npm‑compatible package management & hot reloading — installable via `choco`, `curl`, npm, or Homebrew.

* **[NVM (Node Version Manager)](https://github.com/nvm-sh/nvm):** A CLI tool to install and manage multiple Node.js versions seamlessly on the same machine.

* **[MongoDB Community Server](https://www.mongodb.com/try/download/community):** The free, self‑managed document database for local development. Includes the shell, Compass, and other useful tools.

* **[Postman](https://www.postman.com/):** A leading API development and testing platform with support for collections, automation, mock servers, and collaboration.
